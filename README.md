# FreyLab.systems

Hands-on infrastructure, self-hosting, and homelab engineering — documented in public.

I'm Jake, transitioning into IT the practical way: by building real systems and writing down exactly how and why. Everything here runs (or has run) on **Necropolis**, my multi-node Proxmox cluster at home. I built a small data center in my house to learn what a classroom couldn't teach me — this repo is the proof of work.

## The lab

**Necropolis** — multi-node Proxmox VE cluster.

- **Virtualization:** Proxmox VE (multi-node)
- **Networking:** WireGuard (VPN), Pi-hole (network-wide DNS + ad-blocking)
- **Containers/services:** Docker
- **AI:** local LLMs via Ollama
- **OS/tooling:** Linux, the terminal, self-hosting
