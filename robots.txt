# robots.txt for FreyLab.systems
# Format: RFC 9309 <https://www.rfc-editor.org/rfc/rfc9309>
#
# Posture: everything published here is public on purpose. Search
# crawlers, AI training crawlers, and AI answer engines all get the
# same open grant. Nothing on this site is gated or paywalled, so
# there is nothing to withhold.
#
# To block one specific bot later, give it its OWN group:
#
#     User-agent: SomeBot
#     Disallow: /
#
# Per RFC 9309 a crawler obeys only the single most specific group
# whose User-agent matches its name, and ignores every other group.
# So a named group fully REPLACES the "*" rules below for that bot —
# it does not inherit them, and group order in the file is irrelevant.
#
# On the bare "Disallow:" below — RFC 9309's ABNF explicitly permits an
# empty pattern (rule = ... (path-pattern / empty-pattern)), and by
# convention going back to the 1994 standard every real parser reads it
# as "nothing is forbidden". The RFC itself never spells that meaning
# out, so "Allow: /" is the line actually doing the work here; the bare
# Disallow is kept because some validators look for the directive by
# name. Where the two could be read as conflicting, RFC 9309 settles it:
# "If an 'allow' rule and a 'disallow' rule are equivalent, then the
# 'allow' rule SHOULD be used."

User-agent: *
Allow: /
Disallow:

# Sitemap is a global directive: it applies to every crawler regardless
# of which User-agent group matched, and RFC 9309 requires it be an
# absolute URL. Generated by jekyll-sitemap.
